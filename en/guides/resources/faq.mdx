<AccordionGroup>
  <Accordion title="What is Starrise, and what does it offer?">
    Starrise is an enterprise AI API aggregation platform. Use one API key and one Base URL to call leading models — including Claude, GPT/OpenAI, Gemini, DeepSeek, Qwen, GLM, Kimi, Grok, and Doubao — and manage usage, billing, and call logs in one place.

    Core capabilities: unified access, intelligent routing and failover, transparent usage and cost, enterprise key and permission management, and 24/7 support from a UAE-based team.

    Browse models in the [Models](/en/guides/system-api/models-list) section of these docs, or in the Starrise marketplace. Use model names exactly as listed, or requests will fail.
  </Accordion>

  <Accordion title="How is billing structured, and how do prices compare with official APIs?">
    Billing is prepaid and usage-based. Top up your balance and each call is deducted at the model's rate, with no monthly fee. Chat models are billed per token; image and video generation models are billed per generation.

    Listed prices match each provider's official list price, so you can compare directly. Rates vary by model: check the marketplace or your quotation. Enterprise customers can contact us for discounted rates. One balance and one bill across providers, plus switching models without re-integrating, also cut admin and switching costs.

    Add credits on the [Top Up page](https://ai.alad.com/console/topup?lang=en). See [Top Up & Payment](/en/guides/resources/payment) for billing details.
  </Accordion>

  <Accordion title="What happens when I run out of credits?">
    API calls return a `402 Payment Required` error. Top up at the [Console](https://ai.alad.com/console/topup?lang=en) to resume usage. Set a balance alert so calls are not interrupted; for enterprise accounts we recommend a threshold of 20% of average monthly spend.
  </Accordion>

  <Accordion title="Do you store my prompts, and is my data used for training?">
    We do not store request content. Prompts, responses, and uploaded files are held in memory only while the request is processed, then released. They are never written to disk or a database, and there is no option to log full request content.

    We retain only call metadata (model, token counts, latency, route, request ID), billing records, and an admin audit trail. Source IPs and error messages are not logged by default; if you enable error logging, they are redacted first.

    Training use, data residency, and deletion depend on the route, the provider's policy, and your contract. Confirm the applicable setup and complete your compliance review before going to production.
  </Accordion>

  <Accordion title="What security settings are available for accounts and API keys?">
    You can set an expiry, spending limit, and IP allowlist on each API key. Keys are masked in the console and never appear in clear text in logs. Use sub-accounts to separate teams: a parent account sees its own and its sub-accounts' data, and a sub-account sees only its own. Accounts support two-factor authentication, passkeys, and enterprise SSO.
  </Accordion>

  <Accordion title="How do I integrate? What is the API endpoint?">
    Sign up at [ai.alad.com](https://ai.alad.com?lang=en) and create an API key in the [Console](https://ai.alad.com/console/token?lang=en). Then replace the Base URL and API key in your existing OpenAI client with your Starrise values. Chat models follow the OpenAI API specification, so no major code changes are needed. Set `base_url` to `https://ai.alad.com/v1`.

    Endpoints follow the pattern `https://ai.alad.com/v1/chat/completions`; copy the exact address from the console. Use model names exactly as listed in the Starrise marketplace, or requests will fail.

    See the [Quick Start](/en/quickstart) for a first request.
  </Accordion>

  <Accordion title="How is Starrise different from going direct to a provider?">
    Integrate once to access multiple leading models, and manage keys, permissions, usage, and billing from one console. You avoid separate contracts, integrations, and reconciliation for each provider, and you are not locked in to any of them.

    Compared with other aggregators, Starrise gives you 24/7 support from a UAE-based team, international and Chinese models through one API, business-ready payment (bank transfer, multiple currencies, formal invoices), and enterprise discounts based on your models and usage.
  </Accordion>

  <Accordion title="How do I get technical support?">
    Our UAE-based team provides 24/7 support via the console, email, or WhatsApp. When reporting an issue, include the request ID, timestamp, model, endpoint, HTTP status code, full error message, client and version, relevant configuration (with API keys redacted), and steps to reproduce. Never share a full API key, password, or wallet private key in a ticket, chat, or screenshot.
  </Accordion>

  <Accordion title="How do enterprise customers top up, make payment, and get invoices?">
    Enterprise top-ups are processed manually by our operations team and are normally credited within 1 working day. Set a balance alert to avoid interrupted API calls; we recommend a threshold of 20% of your average monthly spend.

    You can pay by corporate bank transfer, with settlement in USD, HKD, AED, and other currencies. We send the receiving account and payment details with your invoice. Confirm them with our team before paying, and never use account details from unverified channels.

    Self-serve card top-up is also available on the [Top Up page](https://ai.alad.com/console/topup?lang=en). See [Top Up & Payment](/en/guides/resources/payment).
  </Accordion>

  <Accordion title="How do I create and manage API keys?">
    Go to [Token Management](https://ai.alad.com/console/token?lang=en) in the console to create, view, and disable keys, and assign groups, quotas, and permissions per project, team, or customer. Each key can have its own expiry, spending limit, and IP allowlist; keys are masked in the console and never appear in clear text in logs. Accounts support sub-accounts, two-factor authentication, passkeys, and enterprise SSO.
  </Accordion>

  <Accordion title="How do I view spend and usage detail?">
    Everything is in the console. The dashboard shows your total spend, usage logs break down usage and trends by model, and the billing page records top-ups. To control cost, use multiple keys and groups, quotas, permissions, and balance alerts. We recommend a separate key for each environment and team, and exporting call details regularly to reconcile your bill.
  </Accordion>

  <Accordion title="Is a trial credit available?">
    Yes. We can provision trial credit for teams evaluating Starrise. To request it, tell us your use case, estimated volume, target models, expected concurrency, and preferred testing window.
  </Accordion>
